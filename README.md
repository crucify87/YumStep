# YumStep · Kitchen Remix

레시피를 발견하고, 나만의 버전으로 발전시키는 모바일 중심 웹앱입니다.

## 앱 접속

https://yumstep-kitchen-remix.satiny-charm-2844.chatgpt.site

현재 배포는 Sites의 본인 전용 접근 설정을 사용합니다. 이 GitHub 저장소를 등록하는 것만으로 사이트의 공개 범위가 변경되거나 GitHub Pages가 활성화되지는 않습니다.

## 실행

별도 설치나 빌드 없이 실행할 수 있는 HTML/CSS/JavaScript 앱입니다.

```sh
python -m http.server 8000 --directory dist
```

브라우저에서 http://localhost:8000 을 여세요.

## 구현 기능

- 레시피 및 재료 검색, 조리 시간·알레르기 텍스트 필터
- 대표 사진과 재료·단계·타이머를 포함한 레시피 작성
- 원본 복사로 리믹스 작성, 원작자 크레딧, 재료·단계 변경 비교
- 원본과 파생 레시피의 계보
- 인분별 재료 양 자동 환산 및 장보기 목록
- 단계별 조리 모드, 타이머, 지원 브라우저의 화면 켜짐 유지
- 저장, 좋아요, 별점과 사진 후기, 프로필 이름
- 개인 데이터 JSON 내보내기

## 데이터 및 현재 제한

Google 로그인과 Cloud Firestore(`yumstep-2e08b`)에 연결되어 있습니다. 로그인 전에는 브라우저에 저장하고, 로그인한 뒤에는 `users/{uid}/records/{recordId}`에 본인 기록만 저장합니다. 레시피, 후기, 저장 목록, 좋아요, 프로필 및 대표 이미지를 저장합니다. 다른 기기에서는 같은 Google 계정으로 로그인하고 상단의 동기화를 누르세요. 자동 실시간 갱신은 제공하지 않으며, 여러 기기에서 같은 항목을 동시에 수정하면 마지막 저장 내용이 적용됩니다.

기존 브라우저 기록은 로그인 후 **브라우저 기록 가져오기**로 복사합니다. 계정 기록과 병합하며 원본 브라우저 기록은 유지합니다. 실패한 클라우드 저장은 계정별 로컬 캐시에 함께 보관하고 다시 로그인하거나 동기화를 누르면 재시도합니다. 브라우저 데이터를 지우기 전 저장 상태를 확인하고 내 키친에서 JSON으로 백업하세요.

새 요리 사진과 후기 사진은 저장 전에 축소합니다. 이 단계에서는 Cloud Storage 업로드를 사용하지 않고 작은 사진을 Firestore 기록에 포함합니다. 각 기록의 UTF-8 JSON은 800,000바이트 이하로 제한합니다. 기존 큰 사진이 포함된 기록은 가져오기를 중단하고 원본을 유지합니다. 사진이 많은 공개 서비스로 확장할 때는 Cloud Storage와 별도 업로드 정책이 필요합니다.

공개·팔로워 공개, 실제 팔로우, 댓글, 신고·관리, 단계별 사진, 필수/선택 재료 구분, 구조화된 대체 재료, 영양 계산은 추가 구현이 필요합니다. 등록된 알레르기 텍스트 필터만으로 알레르기 안전을 보장하지 않습니다. g 단위 변환에는 재료별 밀도가 필요합니다.

## Firebase 설정

1. Firestore Standard `(default)` 데이터베이스와 Google 로그인 공급자를 활성화합니다.
2. Authentication의 승인된 도메인에 실제 배포 도메인을 추가합니다. 로컬 로그인 테스트 시 `127.0.0.1` 또는 `localhost`도 추가합니다.
3. 저장소 루트의 `firestore.rules`를 Firebase 콘솔에 게시합니다. 규칙/인덱스는 인증된 Firebase CLI로 `firebase deploy --only firestore --project yumstep-2e08b`를 실행해 배포할 수도 있습니다. Sites 배포는 Firebase 규칙을 자동 배포하지 않습니다.
4. 웹앱 설정은 `dist/firebase-config.js`에 있습니다. 서비스 계정 키나 관리자 자격 증명은 사용하지 않습니다.

## 연결 검증

`node --test tests/firebase-sync.test.mjs`로 계정 분리, 재시도, 계정 전환 경합, 로컬 가져오기 및 크기 제한을 검사합니다. `node serve.mjs`는 `http://127.0.0.1:8173`에서 로컬 미리보기를 제공합니다.

실제 배포 후 Google로 로그인 → 레시피 저장 → 상단에 ‘클라우드에 저장됨’ 확인 → 새로고침/다른 기기에서 동기화 순서로 확인하세요. 실제 Google 계정 로그인과 운영 Firestore 쓰기는 사용자 세션에서 최종 확인이 필요합니다.
