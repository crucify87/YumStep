# YumStep · Kitchen Remix

레시피를 발견하고, 나만의 버전으로 발전시키는 모바일 중심 웹앱입니다.

## 앱 접속

https://yumstep-kitchen-remix.satiny-charm-2844.chatgpt.site

현재 배포는 Sites의 본인 전용 접근 설정을 사용합니다. 이 GitHub 저장소를 등록하는 것만으로 사이트의 공개 범위가 변경되거나 GitHub Pages가 활성화되지는 않습니다.

## 실행

별도 설치나 빌드 없이 실행할 수 있는 HTML/CSS/JavaScript 앱입니다.

```sh
python -m http.server 8000 --directory dist
```

브라우저에서 http://localhost:8000 을 여세요.

## 구현 기능

- 레시피 및 재료 검색, 조리 시간·알레르기 텍스트 필터
- 대표 사진과 재료·단계·타이머를 포함한 레시피 작성
- 원본 복사로 리믹스 작성, 원작자 크레딧, 재료·단계 변경 비교
- 원본과 파생 레시피의 계보
- 인분별 재료 양 자동 환산 및 장보기 목록
- 단계별 조리 모드, 타이머, 지원 브라우저의 화면 켜짐 유지
- 저장, 좋아요, 별점과 사진 후기, 프로필 이름
- 개인 데이터 JSON 내보내기

## 데이터 및 현재 제한

현재는 개인 체험 버전입니다. 레시피·업로드 사진·후기·저장은 현재 브라우저의 localStorage에 저장됩니다. 서버 데이터베이스, 회원가입, 기기 간 동기화는 연결되지 않았습니다. 브라우저 데이터 삭제 시 기록이 사라질 수 있으므로 내 키친에서 데이터를 내보내세요. 가져오기 기능은 아직 없습니다.

공개·팔로워 공개, 실제 팔로우, 댓글, 신고·관리, 단계별 사진, 필수/선택 재료 구분, 구조화된 대체 재료, 영양 계산은 추가 구현이 필요합니다. 등록된 알레르기 텍스트 필터만으로 알레르기 안전을 보장하지 않습니다. g 단위 변환에는 재료별 밀도가 필요합니다.

## 파일

- `dist/index.html`: 화면과 애플리케이션 로직
- `dist/pasta.jpg`, `dist/toast.jpg`, `dist/curry.jpg`: 사용자가 제공한 참고 화면에서 가져온 예시 요리 이미지

공개 서비스에서 예시 이미지와 콘텐츠를 재사용하기 전 사용 권한을 확인해야 합니다.

## 검증

JavaScript 문법, 인분 환산, 저장 레시피 표시, 리믹스 변경점, 계보, 단계 타이머 초기값을 코드로 확인했습니다. 실제 브라우저 화면 검증은 아직 수행하지 않았습니다.

## 향후 개발

1. 인증·서버 저장·파일 업로드
2. 전체 공개 및 팔로워 공개 권한
3. 댓글·팔로우·커뮤니티 피드
4. 신고·관리, 이용약관·개인정보 및 원본 삭제 정책
5. 단계별 사진 및 재료 정보 확장
6. 모바일 설치 및 출시 준비
